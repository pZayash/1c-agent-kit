# Асинхронные методы 1С (`Асинх` / `Ждать` / `Обещание`)

Правила использования асинхронного механизма платформы 8.3.18+. Проект на
`{PLATFORM_BUILD}` (см. `.env.example` потребителя) — механизм доступен везде.

Применяется к клиентскому коду с асинхронными вызовами (`&НаКлиенте`). На сервере
`Асинх`/`Ждать` не работают — там обычная синхронная модель.

Авторитетный справочник по архитектурным ограничениям —
[platform-pitfalls.md](platform-pitfalls.md) (раздел «Внешние компоненты» и др.).
Здесь — практические шаблоны и ловушки.

## Базовые принципы

1. Новая async-функция (суффикс `Асинх`) возвращает объект `Обещание`.
2. `Ждать` — оператор ожидания. Код после `Ждать` не выполняется, пока обещание
   не разрешится.
3. `*Асинх`-методы можно вызывать **только** внутри процедур/функций,
   объявленных с ключевым словом `Асинх`.
4. У `Обещание` три состояния: **Ожидание**, **Успех**, **Провал**.
5. Механизм работает **только на клиенте** (`&НаКлиенте`).

## Соответствие старых и новых методов

Предпочитай новый `*Асинх`-синтаксис вместо `Показать*` с `ОписаниеОповещения`:

| Модальное (запрещено) | Через callback | Новый `Асинх` |
| --- | --- | --- |
| `Предупреждение()` | `ПоказатьПредупреждение()` | `ПредупреждениеАсинх()` |
| `Вопрос()` | `ПоказатьВопрос()` | `ВопросАсинх()` |
| `ОткрытьЗначение()` | `ПоказатьЗначение()` | `ОткрытьЗначениеАсинх()` |
| `ВвестиЧисло()` | `ПоказатьВводЧисла()` | `ВвестиЧислоАсинх()` |
| `НайтиФайлы()` | `НачатьПоискФайлов()` | `НайтиФайлыАсинх()` |
| `ПоместитьФайлы()` | `НачатьПомещениеФайлов()` | `ПоместитьФайлыНаСерверАсинх()` |

## Возвращаемые значения (`Ждать Обещание`)

| Метод | Результат `Ждать Обещание` |
| --- | --- |
| `ПредупреждениеАсинх` | `Неопределено` |
| `ВопросАсинх` | `КодВозвратаДиалога` |
| `ОткрытьЗначениеАсинх` | `Неопределено` |
| `ВвестиЧислоАсинх` | `Число` |
| `НайтиФайлыАсинх` | `Массив` объектов `Файл` |
| `ПоместитьФайлыНаСерверАсинх` | `Массив` `ОписаниеПомещенногоФайла` (успех) / `Неопределено` (провал) |

## Базовый шаблон

```1c
&НаКлиенте
Асинх Процедура МояПроцедура()

    Обещание = ВопросАсинх("Продолжить?", РежимДиалогаВопрос.ДаНет);
    Результат = Ждать Обещание;

    Если Результат = КодВозвратаДиалога.Да Тогда
        // действие
    КонецЕсли;

КонецПроцедуры
```

## Критические правила

### 1. Без `Ждать` исключения тихо теряются

Если вызвать async-функцию без `Ждать` и внутри возникнет исключение — оно
**проглатывается без следа**. Код продолжается, как будто ничего не случилось.

```1c
// ОПАСНО: исключение внутри ВызватьОшибку() потеряно!
Процедура МояПроцедура(Команда)
    ВызватьОшибку(); // async-функция без Ждать
КонецПроцедуры

Асинх Функция ВызватьОшибку()
    ВызватьИсключение "ошибка!"; // никто это не увидит
КонецФункции
```

**Правило.** Всегда используй `Ждать` при вызове `Асинх`-функций, если важен
результат или обработка ошибок. Пропускай `Ждать` только для fire-and-forget,
где результат и ошибки намеренно игнорируются.

### 2. `Асинх` в обработчиках событий формы НЕ блокирует

Обработчики событий формы (`ПриОткрытии`, `ПередЗакрытием`, `ПриЗаписиНаСервере`),
объявленные с `Асинх`, **ведут себя не так, как ожидается** — платформа не
дожидается их завершения.

```1c
// НЕ РАБОТАЕТ: форма всё равно откроется, Отказ = Истина проигнорирован.
&НаКлиенте
Асинх Процедура ПриОткрытии(Отказ)
    Отказ = Истина;                    // платформа уже пошла дальше
    ВызватьИсключение "ошибка!";       // пользователь видит ошибку,
                                       // но форма уже открыта
КонецПроцедуры
```

**Правило.** Не делай обработчики событий формы (`ПриОткрытии`, `ПередЗакрытием`,
`ПриЗаписиНаСервере` и т.п.) асинхронными. Параметр `Отказ` и любое влияние на
ход выполнения формы будут проигнорированы. Вместо этого — вызывай отдельную
`Асинх`-процедуру из обычного обработчика.

### 3. Обработчики команд — async разрешён

В отличие от событий формы, обработчики команд **можно** объявлять `Асинх`:

```1c
&НаКлиенте
Асинх Процедура МояКоманда(Команда)
    Обещание = ВвестиЧислоАсинх(1, "Укажите число");
    Результат = Ждать Обещание;
КонецПроцедуры
```

## Паттерн: вопрос при открытии

`ПриОткрытии` — обычная процедура, вызывает отдельную `Асинх`-процедуру:

```1c
&НаКлиенте
Процедура ПриОткрытии(Отказ)
    ЗадатьВопросПриОткрытии();
КонецПроцедуры

&НаКлиенте
Асинх Процедура ЗадатьВопросПриОткрытии()

    Обещание = ВопросАсинх("Продолжить работу?",
        РежимДиалогаВопрос.ДаНет, , КодВозвратаДиалога.Да);
    Результат = Ждать Обещание;

    Если Результат <> КодВозвратаДиалога.Да Тогда
        ЭтаФорма.Закрыть();
    КонецЕсли;

КонецПроцедуры
```

## Паттерн: вопрос при закрытии

Флаг-переменная предотвращает рекурсию:

```1c
&НаКлиенте
Перем ВопросПриЗакрытииЗадан;

&НаКлиенте
Процедура ПередЗакрытием(Отказ, ЗавершениеРаботы,
        ТекстПредупреждения, СтандартнаяОбработка)

    Если НЕ ВопросПриЗакрытииЗадан Тогда
        ЗадатьВопросПриЗакрытии();
        Отказ = Истина;
    КонецЕсли;

КонецПроцедуры

&НаКлиенте
Асинх Процедура ЗадатьВопросПриЗакрытии()

    Обещание = ВопросАсинх("Закрыть форму?",
        РежимДиалогаВопрос.ДаНет, , КодВозвратаДиалога.Да);
    Результат = Ждать Обещание;

    Если Результат = КодВозвратаДиалога.Да Тогда
        ВопросПриЗакрытииЗадан = Истина;
        ЭтаФорма.Закрыть();
    КонецЕсли;

КонецПроцедуры

ВопросПриЗакрытииЗадан = Ложь;
```

## Паттерн: файловый workflow

```1c
&НаКлиенте
Асинх Процедура ЗагрузитьФайлыНаСервер()

    Обещание = НайтиФайлыАсинх(ПутьКПапке, "*.*", Ложь);
    НайденныеФайлы = Ждать Обещание;

    ДобавляемыеФайлы = Новый Массив;
    Для Каждого НайденныйФайл Из НайденныеФайлы Цикл
        Описание = Новый ОписаниеПередаваемогоФайла;
        Описание.Имя = НайденныйФайл.ПолноеИмя;
        ДобавляемыеФайлы.Добавить(Описание);
    КонецЦикла;

    Обещание = ПоместитьФайлыНаСерверАсинх(
        , , ДобавляемыеФайлы, ЭтаФорма.УникальныйИдентификатор);
    Результат = Ждать Обещание;

КонецПроцедуры
```

## HTTP-методы (8.3.21+)

`HTTPСоединение` имеет async-аналоги (суффикс `Асинх`): `ВызватьHTTPМетодАсинх`,
`ЗаписатьАсинх`, `ПолучитьАсинх` и т.п. Те же правила: вызывающая процедура
должна быть `Асинх`, результат и исключения получай через `Ждать`.
