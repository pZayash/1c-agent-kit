# Подписки на события 1С

## Архитектура

Глобальные подписки проекта уже ловят события для ВСЕХ документов, справочников и регистров.
Модуль `яя_` — диспетчер: проверяет, включена ли подписка для объекта, и делегирует в метод объекта.

**Не создавай новую подписку** — добавляй метод в модуль объекта.

> Если нужна новая подписка (нестандартное событие, отдельный обработчик) — см. [research/research_яя_ПодпискиНаСобытия.md](/research/research_яя_ПодпискиНаСобытия.md). Это задача архитектора.

---

## Подключение подписки в модуле объекта

Два шага: **зарегистрировать** использование и **реализовать** обработчик.

### 1. Регистрация (секция инициализации модуля)

Вызови `яя_.ПодпискиНаСобытия_УстановитьИспользование` для каждой нужной подписки.
Идентификатор подписки — элемент перечисления `Перечисления.яя_Подписки`:

```bsl
// Инициализация
яя_.ПодпискиНаСобытия_УстановитьИспользование(ЭтотОбъект, Перечисления.яя_Подписки.яя_ОбработкаЗаполнения);
яя_.ПодпискиНаСобытия_УстановитьИспользование(ЭтотОбъект, Перечисления.яя_Подписки.яя_ОбработкаПроведения);
яя_.ПодпискиНаСобытия_УстановитьИспользование(ЭтотОбъект, Перечисления.яя_Подписки.яя_ПриКопировании);
```

Актуальный список элементов перечисления — в `conf/Enums/яя_Подписки.xml`.

### 2. Реализация обработчика

Имя процедуры **совпадает с именем элемента** `Перечисления.яя_Подписки`. Сигнатура зависит от события:

```bsl
// яя_ПередЗаписью — документ
Процедура яя_ПередЗаписью(Отказ, РежимЗаписи, РежимПроведения) Экспорт
КонецПроцедуры

// яя_ПередЗаписью — справочник
Процедура яя_ПередЗаписью(Отказ, РежимЗаписи) Экспорт
КонецПроцедуры

// яя_ПередЗаписью — регистр сведений
Процедура яя_ПередЗаписью(Отказ, РежимЗаменыНаборов) Экспорт
КонецПроцедуры

// яя_ПриЗаписи — документ или справочник
Процедура яя_ПриЗаписи(Отказ) Экспорт
КонецПроцедуры

// яя_ОбработкаПроведения
Процедура яя_ОбработкаПроведения(Отказ, РежимПроведения) Экспорт
КонецПроцедуры

// яя_ОбработкаПроверкиЗаполнения
Процедура яя_ОбработкаПроверкиЗаполнения(Отказ, ПроверяемыеРеквизиты) Экспорт
КонецПроцедуры

// яя_ОбработкаЗаполнения
Процедура яя_ОбработкаЗаполнения(ДанныеЗаполнения, ТекстЗаполнения, СтандартнаяОбработка) Экспорт
КонецПроцедуры

// яя_ПриКопировании
Процедура яя_ПриКопировании(КопируемыйОбъект) Экспорт
КонецПроцедуры
```

Процедуры должны быть **`Экспорт`**.
