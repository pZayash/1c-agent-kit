# Правила планирования для ИИ-агентов

- При написании плана будь предельно краток, жертвуй грамматикой ради краткости
- Ничего не пиши в файлы, планируй в режиме `Только чтение`
- Репозиторий проекта очень большой, если что-то надо найти, сначала спроси у меня, прежде чем искать самому
- Если ищешь сам, используй skill `1c-configdump-fast-search`
- Спроси у меня подробнейшим все неочевидные вопросы, если такие есть
- Продолжай спрашивать меня, пока не будут получены ответы на все вопросы, прежде чем записать план в файл
- В конце каждого плана дай мне список оставшихся вопросов, если такие есть

## Документы

Если в задании просят доработать проведение документа, надо провирить, разрешено ли проведение этого документа в метаданных. Примеры документов у которых отключено проведение - Документы.ЗаказПокупателя, Документы.яя_КоммерческоеПредложение

```1c
проведениеЗапрещено = Метаданные.Документы.яя_КоммерческоеПредложение.Проведение = Метаданные.СвойстваОбъектов.Проведение.Запретить;
```

Не планируй доработки првоедения в документах без проведения, уточни у пользователя.
