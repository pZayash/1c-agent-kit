# close-chat-1c — 1C-дополнение к close-chat

Читается из `close-chat` до шага 1, когда у
потребителя выбран стек `1c`. Конкретизирует формулировки пайплайна под 1С;
шаги и гейты — по core-версии.

## Шаг 0 — operator-checklist

«Проверки в целевом runtime» — это проверки в ИБ (smoke, прогоны в базе).

## Шаг 0б — темы memory-уроков

Кандидаты на перенос в `docs/ai/` — записи `memory/` по:

1. правке XML `conf/` (метаданные, формы, load);
2. WEB UI-тестированию (`web-test`, гибрид с MCP).

## Шаг 3 — зоны смешанных файлов

«Исходники» для детекта смешанности — `conf/` и `cfe.xml/`: маркеры `№%`
живут в BSL/XML исходников конфигурации и расширений.
