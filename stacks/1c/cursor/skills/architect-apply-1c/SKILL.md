# architect-apply-1c — 1C-дополнение к architect-apply

Читается из `architect-apply` до шага 1, когда у
потребителя выбран стек `1c`. Конкретизирует стоп-зону и стандарты под 1С;
пайплайн — по core-версии.

## Стоп-зона — 1С-конкретика

- **Тяжёлый XML**: `Form.xml`, XML метаданных объектов (`*.xml` справочников/
  документов/перечислений), MXL-макеты. Их создаёт/правит исполнитель скиллами
  `meta-*`/`form-*`/`mxl-*`.
- **Тесты и БД**: прогон тестов, загрузка в dev/prod-ИБ, отладка, smoke —
  исполнителю.

## Ядро — стандарты .bsl

- Исходный код — `.bsl`; оболочку `.xml` общего модуля делает исполнитель.
- Стандарты проекта: префикс `яя_`, локалы с малой буквы, параметры `п-`,
  комментарий модификации по `MODIFICATION_COMMENT_TEMPLATE`, doc-комментарии.
- Статический чек — `bsl-check` ([bsl-check](../bsl-check/SKILL.md)) через
  `bash tools/sandbox/run.sh` до **OK**.

## Executor-task — 1С-детали

- Скиллы исполнителя: `meta-*`/`form-*`/`mxl-*` для метаданных, форм, макетов.
- DoD: зелёные `*-validate`, `bsl-check` OK, `<Comment>` поднят,
  перенос/печать работают.
- «Расширения стека» — CFE (`cfe.xml/`): не трогать без указания.
