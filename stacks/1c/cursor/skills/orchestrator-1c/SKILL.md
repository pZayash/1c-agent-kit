# orchestrator-1c — 1C-дополнение к orchestrator

Читается из `orchestrator` до шага 1 цикла, когда у
потребителя выбран стек `1c`. Конкретизирует «общий ресурс» и тяжёлые
операции под 1С; цикл и политики — по core-версии.

## Общий ресурс — общая ИБ

- «Целевой runtime» — общая ИБ. Политика `main` = union: всё, что уже в ИБ,
  должно быть закоммичено в `main` до первой полной загрузки — иначе загрузка
  вытеснит чужие незакоммиченные объекты из метаданных.
- Мерж и загрузку исполняет дочка-интегратор —
  [integrator](../integrator/SKILL.md).
- «Долгие операции на общем ресурсе» (этап B для дочки) — загрузка
  конфигурации в общую ИБ, `/UpdateDBCfg`.
- Долгоживущий фоновый процесс, который детектит сторож, — загрузка
  конфигурации может идти часами без событий.

## Тяжёлые артефакты стека

`Form.xml`, XML метаданных объектов, MXL-макеты — правит дочка, не ты и не
твоё ревью «на глаз».
