# plan-creation-rules-1c — 1C-дополнение к plan-creation-rules

Читается из `plan-creation-rules` до шага 1, когда у потребителя выбран
стек `1c`. Дополняет правила планирования 1С-конкретикой.

## Документы

Если в задании просят доработать проведение документа, надо провирить, разрешено ли
проведение этого документа в метаданных. Примеры документов у которых отключено проведение -
Документы.ЗаказПокупателя, Документы.яя_КоммерческоеПредложение

```1c
проведениеЗапрещено = Метаданные.Документы.яя_КоммерческоеПредложение.Проведение = Метаданные.СвойстваОбъектов.Проведение.Запретить;
```

Не планируй доработки првоедения в документах без проведения, уточни у пользователя.
